Voice Operated Lift is an embedded systems project that explores the use of voice commands to control lift operations. The system demonstrates hands-free lift operation using speech recognition and microcontroller-based automation.

Project source: "Original B.E. Project" (https://github.com/rushi-56/Voice-Operated-Lift-System)
author: Rushikesh Markad

---

📖 Overview

This project demonstrates lift operation through speech recognition, enabling users to:

- Call the lift to a specific floor.
- Open and close lift doors.
- Move between floors using voice commands.

The described system integrates voice modules, microcontrollers, and motor drivers for automated lift control.

---

✨ Features

- Hands-free Control: Operates using voice commands.
- User Accessibility: Designed to support users with mobility challenges.
- Multi-floor Support: Supports commands for multiple floors.
- Safety Integration: Describes obstruction detection.
- Customizable Commands: Supports predefined voice commands.

---

🛠️ Tech & Infrastructure

Hardware

- Microcontroller: Arduino / Microcontroller Board
- Voice Recognition Module
- Motor Driver Circuit
- Lift Motor: DC/AC
- Safety Sensors: For obstruction detection
- Power Supply Unit

Software

- Programming Language: Embedded C / Arduino C
- IDE: Arduino IDE
- Control Logic: Voice input → Microcontroller processing → Motor control signals

---

⚙️ System Flow

1. Voice Command Input — User speaks a predefined command.
2. Voice Recognition Processing — Voice module identifies the command.
3. Microcontroller Control — Command is mapped to a lift function.
4. Motor Driver Activation — Controls lift movement or door operation.
5. Safety Checks — Obstruction sensors are described as ensuring safe operation.
